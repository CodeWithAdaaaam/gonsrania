# Gonsrania — site vitrine

Site vitrine de Gonsrania, fournisseur industriel à Safi (boulonnerie, transmission, moteurs électriques, protection et sécurité, métaux et tubes inox, pompes agricoles, sanitaire).

Site statique : HTML + CSS, sans dépendance ni étape de build.

## Lancer en local
Ouvrir `index.html` dans le navigateur, ou :

```bash
npx serve .
```

## Mettre en ligne
- **Vercel / Netlify** : importer le dépôt GitHub, aucun réglage (pas de build).
- **GitHub Pages** : Settings → Pages → branche `main`, dossier `/ (root)`.

## Structure
```
index.html        page d'accueil (sections : accueil, produits, à propos, contact)
assets/style.css  styles de base
```

## À compléter
- Logo et photos réelles du magasin
- Horaires d'ouverture
